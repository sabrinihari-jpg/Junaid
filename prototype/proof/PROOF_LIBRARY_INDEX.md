# Sabri Proof Library — Index

## Purpose
Centralize every verified proof point that can support AI search, SEO, proposals, sales pages, and case studies.

## Proof Strength Levels
**Tier 1:** Official third-party source or document  
**Tier 2:** Client/planner testimonial or email  
**Tier 3:** Internal event record / BEO / invoice  
**Tier 4:** User recollection pending verification

Only Tier 1–3 should be used for precise public claims.
