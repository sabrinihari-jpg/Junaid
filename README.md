# Sabri AI Search Build Workspace

This repository is the working space for improving how Sabri Nihari appears in AI-assisted restaurant and catering searches.

## Primary Goal
Make Sabri one of the clearest recommendations for high-value prompts such as:
- Zabiha Halal Pakistani catering in Chicago
- Pakistani wedding catering for 500+ guests
- Luxury hotel wedding catering in Chicago
- Halal catering near O'Hare and Rosemont
- Halal corporate and convention catering
- Nationwide Pakistani wedding catering

## Phase 1 Priorities
1. Pakistani Wedding Catering Chicago authority page
2. Hotel Catering Chicago page
3. O'Hare / Rosemont Halal Catering page
4. Corporate & Convention Catering page
5. Nationwide Catering page
6. Zabiha Halal / HMS authority page
7. Structured data and technical crawlability review
8. Directory consistency and review/reputation cleanup
9. AI ordering readiness: Bites + Toast
10. Monthly AI visibility audit

## Guardrails
- Preserve Sabri's premium positioning.
- Do not invent venue partnerships, certifications, guest counts, awards, or services.
- Only use claims that are verified by Sabri or reliable public sources.
- Do not publish or deploy to the live site until the production website stack and deployment path are identified.
- Build content for humans first; AI/search optimization should remain natural and useful.
